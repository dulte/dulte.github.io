SaltBloc

Generate a deterministic secure key from your passwords.

Copying the generated key may store it in your system clipboard history.

About SaltBloc

SaltBloc derives a deterministic secure key from:

  • a secret password
  • a site-specific password
  • a selected key size (128-bit or 256-bit)

The generated key is shown on the page and can be copied manually.

PBKDF2 with SHA-256 is used to derive the key material.

This app can be installed as a PWA for a more app-like experience.
